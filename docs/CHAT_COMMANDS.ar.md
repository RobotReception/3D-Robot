# إصدار الأوامر للروبوت من الشات

يمكنك الآن أن تكتب (أو تقول بالميكروفون) أمراً للروبوت مثل **«تقدم للأمام»** فينفّذه فوراً، دون الحاجة إلى Gemini ودون إنترنت،
وبنفس الشات الذي تسأله فيه. وإذا لم يكن كلامك أمراً (مثل «ما شروط القبول؟») يذهب إلى Gemini كالمعتاد.

> التشغيل: `npm run gemini:mock` (أو `npm run gemini:server` مع مفتاحك) ثم `npm run dev` وافتح `http://localhost:5173/examples/gemini.html`.
> أسفل الشات أزرار سريعة (تقدم، تراجع، يساراً، يميناً، لوّح، المكتب، مكانك، قف) وزر «؟ الأوامر» لعرض القائمة.

## كيف يعمل

```
رسالتك ─► هل هي أمر مفهوم بالكامل؟ ──نعم──► تنفيذ فوري (بدون LLM)
                    │                         ├─ يقول كلمة تأكيد قصيرة («حاضر»…) بصوته أثناء التنفيذ
                    │                         ├─ يمشي / يستدير / يلوّح… خطوة بخطوة، ويخبرك إن عاقه عائق
                    │                         └─ يظهر في الشات سجّل بالخطوات: ✓ تقدّم 2 م
                    └──لا──► Gemini يجيب بصوته، وقد يضيف وسم [action=…] ليحرّك الروبوت (انظر أسفل)
```

- المحلّل (`src/engine/chatCommands.ts`) يفهم العربية الفصحى واللهجات الشائعة والإنجليزية، مع الأرقام العربية والكلمات («مترين»، «ثلاثة أمتار»، «نصف متر»، «خمس وأربعين درجة»).
- إن فهم **جزءاً** فقط من الجملة لا ينفّذ شيئاً ويرسلها إلى Gemini (لا تنفيذ نصف مفهوم).
- النفي («لا تتقدم»، «don't move») لا يُنفَّذ أبداً. والجمل الطويلة (> 22 كلمة) تعتبر كلاماً عادياً.
- الأمر الجديد يقاطع الكلام الجاري (الروبوت يسكت وينفّذ). «قف» يوقف المشي والكلام فوراً. زر ⏹ يفعل الشيء نفسه.
- الميكروفون 🎤 يقاطع كلام الروبوت لكنه **لا** يوقف مشيته.

## قائمة الأوامر

| النوع | أمثلة عربية | أمثلة إنجليزية |
|---|---|---|
| تقدّم | تقدم · تقدم للأمام · تقدم مترين · امش 3 أمتار · تقدم نصف متر · تقدم 50 سم · خطوة للأمام · امش ببطء · تقدم بسرعة | walk forward · move forward 2 meters · take two steps · walk slowly forward |
| تراجع / جانبياً | تراجع · ارجع للخلف مترين · خذ خطوتين للخلف · تحرك لليمين متر · تحرك يساراً مترين | step back · take two steps back · move left 3 metres |
| استدارة | استدر يميناً · استدر يساراً 45 درجة · استدر للخلف · لف حول نفسك · ربع دورة لليمين | turn right · turn left 45 degrees · turn around · spin around |
| أماكن | اذهب إلى المكتب (أو الاستقبال) · روح للنافذة · اذهب إلى المقعد · اذهب إلى المنتصف · تعال (هنا) | go to the desk · walk to the window · go to the bench · come here |
| عودة وإيقاف | عد إلى مكانك · قف · توقف | go back to your place · go home · stop |
| حركات | لوّح · ودّع · انحنِ · أومئ · هز رأسك لا · افرح · احزن | wave · wave goodbye · bow · nod · shake your head |
| تعابير | ابتسم · فكّر · ارمش | smile · think · wink |
| نظر وإشارة | انظر إليّ · انظر يميناً · التفت يساراً · انظر للأعلى · أشر إلى اليمين · أشر إلى المكتب | look at me · look left · look up · point left · point to the window |
| ألوان | غيّر لون السترة إلى الأزرق · غيّر لون العيون للأخضر | change the uniform to red · make the eyes purple · reset colors |
| كلام | قل مرحباً بكم في جامعة الرازي | say welcome to the university |
| صيغ مهذّبة | من فضلك تقدم · هل تستطيع التقدم للأمام؟ | can you please go straight 5 meters |

### أوامر متتابعة
اجمع عدة أوامر بـ «ثم» أو «و» أو الفاصلة (حتى 6 أوامر) فتُنفَّذ بالترتيب:

- «اذهب إلى المكتب ثم لوّح ثم عد إلى مكانك»
- «استدر يساراً ثم تقدم 3 أمتار»
- *walk forward two meters and then turn left*

### الاتجاهات
الاستدارة لليسار = زاوية موجبة، لليمين = سالبة (من وجهة نظر الروبوت نفسه). «تراجع» و«لليمين/لليسار» تعني
أن الروبوت **يدور ثم يمشي ثم يعود لاتجاهه الأصلي** (الروبوت ثنائي الأرجل ولا يمشي للخلف بطريقة المشي العكسي).

### الأماكن المعرّفة في اللوبي
`desk` المكتب/الاستقبال (يقف أمامه ويواجهه) · `window` النافذة الزجاجية · `bench` المقعد · `center` المنتصف · `front` أمام المشاهد (تعال) · `plant` النبتة.
وللتعديل أو إضافة أماكن لبيئتك:

```ts
new RobotAssistant(robot, {
  chat, tts,
  commands: {
    places: { lab: { x: 3, z: -2, facing: 90 }, ...LOBBY_PLACES }, // facing بالدرجات، 0 = نحو +Z
    home: { x: 0, z: 0, facing: 0 },   // مكان «عد إلى مكانك» (الافتراضي: حيث وُلد الروبوت)
    maxMeters: 6,                      // أطول حركة واحدة
    voice: true,                       // false = بدون صوت التأكيد
  },
});
// commands: false  ← يلغي الأوامر المحلية تماماً
```

ملاحظة: الأماكن الجديدة تعمل فوراً مع وسوم Gemini (`[action=goto:lab]`، وتظهر في الـ prompt تلقائياً عبر `buildSystemPrompt({ persona: { actions: { places: [...] } } })`)، أما لتفهمها الأوامر المكتوبة («اذهب إلى المختبر») فأضف مرادفاتها في جدول `PLACES` داخل `src/engine/chatCommands.ts`.

## العوائق والجدران

الروبوت يعرف عالم اللوبي (جدران، مكتب، مقعد، نباتات): يخطّط مساراً حول الأثاث ولا يخترقه.
- إن عاقه عائق قبل إتمام المسافة يقف ويقول: «لا أستطيع المتابعة، هناك عائق. تحركت 1.2 متراً فقط» (ويظهر ✗ باللون البرتقالي في السجل).
- إن كان المكان لا يمكن الوصول إليه يقول «لا أستطيع الوصول إلى هناك».
- الحد: الذراعان لا تتجنبان العوائق، وجسم الروبوت يُحسب كدائرة.

## ربط Gemini بالحركة (وسوم `[action=…]`)

عندما تسأل Gemini سؤالاً يتضمن حركة («أرني الطريق إلى مكتب الاستقبال»)، يعلّمه الـ system prompt أن يضع وسماً في بداية الجملة،
فيمشي الروبوت **حين تبدأ تلك الجملة بالنطق** (ولا يُنطق الوسم أبداً):

```
[action=goto:desk]بكل سرور، تفضل معي إلى مكتب الاستقبال. [gesture=pointing]هو هنا، وفريقنا سيساعدك.
```

| الوسم | المعنى |
|---|---|
| `[action=forward:2]` `back` `left` `right` | مسافة بالأمتار (حتى 6) |
| `[action=turn_left:90]` `[action=turn_right:45]` | استدارة بالدرجات |
| `[action=goto:desk]` | مكان من القائمة |
| `[action=home]` | العودة للمكان الأصلي |
| `[action=look:user]` (`left right up down forward`) | النظر |
| `[action=point:left]` (`right forward <place>`) | الإشارة |

- الوسوم غير الصالحة تُتجاهل بصمت. التنفيذ بالتتابع، ويكتمل المشي قبل أن تنتهي الإجابة.
- الأوامر الصريحة البسيطة («تقدم») لا تصل إلى Gemini أصلاً؛ تُنفَّذ محلياً أسرع وبدون تكلفة.
- لإيقافها: `buildSystemPrompt({ actions: false })` (أو `persona: { actions: false }`).
- أحداث للواجهة: `assistant.on("command", …)` عند فهم أمر، و`assistant.on("action", { action, result, index, source })` عند انتهاء كل خطوة
  (`source`: `"chat"` أو `"llm"`)، وحالة `acting` أثناء التنفيذ.

## للمطوّرين

```ts
import { parseCommands, executeActions, LOBBY_PLACES } from "robot-avatar-engine";

const cmd = parseCommands("تقدم مترين ثم لوّح");        // { actions: [...], lang: "ar" } أو null
await executeActions(robot, cmd!.actions, { places: LOBBY_PLACES, home: { x: 0, z: 0 } });
```

- `src/engine/chatCommands.ts` المحلّل (نصوص ← `RobotAction[]`) · `src/engine/actions.ts` المنفّذ + وسوم `[action=…]` · الدمج في `src/engine/assistant.ts`.
- الاختبارات: `tests/commands.test.ts` (محلّل: >140 جملة) · `tests/actions.test.ts` (روبوت حقيقي في اللوبي) · ومسار e2e في `tests/e2e/run.mjs`.
- لإرسال جملة تشبه الأمر إلى Gemini رغم ذلك: `assistant.ask(text, { commands: false })`.

## حدود صريحة

- المحلّل قائم على قواعد: يغطي الصيغ الشائعة لا كل لهجات العربية؛ ما لا يفهمه بالكامل يذهب إلى Gemini (الذي قد يحرّك الروبوت بالوسوم).
- لم أجرّب Gemini الحقيقي بعد (الاختبارات على خادم Gemini تجريبي)؛ التزام النموذج الحقيقي بالوسوم يعتمد على النموذج وسيحتاج ربما لضبط الـ prompt.
- لا مشية عكسية: التراجع = دوران + مشي + عودة للاتجاه.
- مسافة الحركة تقريبية (±5 سم) والاستدارة (±2°) بسبب نعومة الحركة.
