# Motion catalogue

> Generated by `tools/gen_docs.ts`. Every built-in clip below is also exported as editable JSON in `docs/motions/` (raw joint-space keys sampled from the code) — use them as examples when you or an AI author new motions ([MOTION_AUTHORING.md](MOTION_AUTHORING.md)).

Not clips: **Walking / Turning** are procedural IK locomotion (`walkTo`, `turnTo`, `playAnimation("walking")`), **Speaking** = `speak()` (talk gestures + lip-sync + head-bob). Priorities and channels: [ANIMATION.md](ANIMATION.md).

### `idle`

Natural standing: breathing, weight shift, micro head and arm motion.

- **Use:** Base pose; always running underneath everything.
- **Type:** loop, 12 s, priority 0, fade in/out 0.6/0.6 s
- **Channels:** torso, head, armL, armR, fingersL, fingersR
- **Play:** `robot.playAnimation("idle")` or `{"cmd":"playAnimation","name":"idle"}`
- **As data:** [motions/idle.json](motions/idle.json) (sampled keyframes, same format you can author)
